# Signal-CANdy P0/P1 + GAS G4 HIL 완료 보고서

## 📝 작업 요약

Signal-CANdy의 staged IR/AST 전 behavior baseline인 P0 AOT↔SCIMG differential, P1 runtime boundary/adversarial conformance, 그리고 기존 GAS/MDL/SDP adapter를 통과하는 CC1A-Test-1 STM32G474 HIL을 완료했다.

Host/native exhaustive gate와 target representative gate를 분리했다. Signal-CANdy semantics는 host/native에서 넓게 검증하고, target에서는 실제 `MDL_FdCan_RxCaptureV1_Record_t -> sc_frame_t -> Signal-CANdy -> GAS_FdCan enqueueTracked` 경로와 activation transaction을 NI CAN3으로 검증했다. GAS_BSP/GAS_SDP private repositories는 수정하지 않았다.

사용자 steering에 따라 G4 validation을 우선하며 `G4-Bootloader-Capacity`를 별도 claim했다. G0 실기기 validation은 board capacity가 확보될 때 successor run으로 이관한다.
