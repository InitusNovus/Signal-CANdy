## 📌 정정 사항 (1차 보고서 대비)

1. 1차 보고서의 "64-byte FD normalization" 주장은 adapter가 `SC_FRAME_FD`를 실제로 설정하지 않은 상태의 관찰이었다. 수정 후 재검증으로 현재 주장이 실제 FD 플래그 경로에 바인딩되었다.
2. freshness/mux/extended "target representative" 표현은 target 수신 영수증이 없는 출력이었다. 현재 runner는 이를 출력하지 않으며, 해당 경계는 native C002 host suite 소관으로 명시된다.
3. G4-Bootloader-Capacity claim(fa422eed)은 사용자 지시로 release되어 set 상태가 Available이다. 유지 claim은 CC1A-Test-1(cd519cfa) 단 하나다. G4-first 검증은 유지 중인 G474 DUT(CC1A-Test-1)에서 수행되었으며 G0 hardware는 계속 deferred다.
