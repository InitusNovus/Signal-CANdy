# CC1A 실기기 Signal-CANdy 런타임 검증 — 세션 보고

## 📝 작업 요약

이슈 #17 vertical slice의 실기기 증명: Signal-CANdy가 생성한 `.scimg` 런타임 이미지와 allocation-free C99 디코더를 포함한 STM32G474 베어메탈 앱을 CC1A(TT_CC1A26_0025)에 TT_Host UART로 플래시하고, NI CAN3를 통해 CAN/CAN FD 벡터를 주고받아 디코드 정확성을 실기기 검증했다. 신규 sibling repo `CC1A_SignalCANdy_RuntimeTest` (커밋 f4b3ed9, 356 files)에 펌웨어·호스트 하니스·동기화 도구가 모두 포함됐다.

## 🛠 변경 상세

- **CC1A_SignalCANdy_RuntimeTest/** (신규): firmware (stage6 스켈레톤 포크, App_SignalCandyRuntime: scimg 임베드→sc_decode→0x7A0 FD 진단+0x7F1 하트비트, TT_Host 앱모드/bootloader-enter 유지, text 48,324B / app 94,208B 영역 내, VTOR 0x8000), tools/sync_signal_candy.py (결정적 헤더 생성, scimg sha256 d25dc336..4726b 본체와 동일), host/sc_validate.py (nixnet FD-BRS 500k/2M 하니스)
- **Signal-CANdy 본체**: 변경 없음 (회귀 없음, tmp/ 캡처 파일만)
- 벤치 claim 437b383d 유지, ST-Link 미사용, TT_Host 데몬 127.0.0.1:9802 전용
