# CC1A Signal-CANdy TX HIL 검증 보고서

## 📝 작업 요약

Signal-CANdy issue #19의 CC1A TX 하드웨어 인 더 루프 검증을 완료했다. `scimg_tx_demo` DBC/pool/binding fixture에서 생성한 TX-enabled `.scimg`와 C99 runtime을 형제 저장소 `CC1A_SignalCANdy_RuntimeTest` 펌웨어에 포함하고, TT_Host UART/IAP로 플래시한 뒤 NI CAN3에서 classic counter, 64-byte FD-BRS, mux payload를 실측했다.

## 🛠 변경 상세

Signal-CANdy:

- `examples/scimg_tx_demo/tx_demo.dbc`: classic counter/LE/Motorola, 64-byte FD, mux TX 메시지 정의.
- `examples/scimg_tx_demo/pool.json`: TX 방향 5-slot 정적 pool 계약 정의.
- `examples/scimg_tx_demo/binding.json`: logical ID 1/2/3, modulo-16 counter, identity conversion 정의.

형제 저장소:

- RX/TX fixture 선택 및 명시적 runtime overwrite를 지원하도록 동기화 도구 확장.
- commit `191048b` C99 runtime/API 동기화 및 `scimg_tx_demo.h` 생성.
- compile-time TX HIL 모드에서 logical ID 1/2/3 prepare/enqueue/commit 구현; heartbeat 이후 100 ms 간격으로 classic→FD→mux를 stagger하여 bounded GAS TX queue를 넘지 않도록 함.
- `host/sc_validate_tx.py`와 TX HIL 절차/프레임 문서 추가.

## ✅ 테스트 결과

- TX `.scimg` 2회 생성 byte-identical: 432 bytes, SHA-256 `681fa350bf5fc1ac4c248ac7ec8bbb1d0962a958d774c8b8ae04abfe723ba013`.
- Inspector: feature flags `1`, legacy RX messages `0`, TX messages `3`, TX programs `5`, counters `1`, CRC valid.
- 형제 저장소 sync 2회 byte-identical; 두 runtime 파일이 Signal-CANdy `191048b586a0fd31338b139fef9f2a3dd1c028c1`과 동일.
- 최종 TX firmware clean build 성공: SHA-256 `195ac69daf50c460984425a77c36024b105a78b18d3c1a7cf533bee483cb619a`.
- ELF `.isr_vector` 주소 `0x08008000`, reset vector `0x0801441D`, BIN 내 exact TX image/feature bit/TX section magic 확인.
- `python -m py_compile` 및 `--list-expectations` exact output 통과.
- runtime/App 소스에 직접적인 malloc/calloc/realloc/free 호출 없음. ELF의 legacy GAS/Bridge buffer allocation은 기존 인프라로 확인됨.
- TT_Host daemon `127.0.0.1:9802` 전용 플래시 성공(operation `fc4a0940`), ST-Link/SWD 사용 없음.
- Cold reset 직후 NI CAN3 HIL `ALL PASS (4 frame expectations)`:
  - `0x321` classic: 첫 counter `0`, payload `00 34 12 FF 00 00 00 00`.
  - `0x322` FD-BRS 64-byte: `EF BE` + 62 zero bytes.
  - `0x323` classic mux: selector `1`, branch `0x0234`.
  - 다음 `0x321` counter `1`, payload `01 34 12 FF 00 00 00 00`.
- 초기 동시 enqueue에서 마지막 mux frame이 GAS queue 용량으로 drop되는 결함을 HIL에서 발견; 100 ms stagger로 수정 후 통과.
- Host C99 probe에서도 logical ID 1/2/3 모두 동일 payload를 생성해 image/runtime와 펌웨어 queue 문제를 분리 확인.
- daemon disconnect/종료 및 QA 임시 executable/디렉터리 제거 확인.
